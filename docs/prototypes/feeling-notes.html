Notes on a Feeling

A few words of your own against a single feeling — irate, but only about the meeting — typed without leaving the keyboard, and gone again the moment you clear the box. Two placements, each shown in the grid and in the walk. Everything below is live: click into a demo and use the keys.

The contract

One key opens it, one key closes it

The note attaches to whatever the screen is already about: the word under focus in the grid, the word on the card in the walk. Nothing else on either screen changes meaning, so there is one key to learn and it means the same thing in both places.

While the picker has focus
NWrite a note on this word, or open the one already there. Focus moves into the box.
EnterCommit. In the grid it marks the word and hands focus back to it; in the walk it answers yes and deals the next card.
Enter on emptyDeletes the note. Clearing the box is the delete; there is no second control for it.
EscPuts the box back the way it was found and closes it. Escape never leaves the screen while a note is open.
← →In the walk they answer — except inside the box, where they are the caret. The box stops them at its edge.

A note only exists on a word that is picked. There is nothing a note on an unpicked feeling could mean and nowhere for it to be written — only marked words reach the note in the vault. So the rule runs both ways: committing a note marks the word, and unmarking a word takes its note with it. In the walk, where every card is answered, keeping a note is the yes — N, type, Enter answers the card and deals the next one, and ← on a noted card drops the note along with the word.

Option A

In the strip

The note is typed where the word is already being explained — under the definition in the grid's gloss strip, under the definition on the card. Nothing moves except the one line the box occupies, and in the grid nothing above it moves at all: the strip is the last thing in the body, so it grows downwards, which is the direction the modal already grows in.

Option B

Make room

The screen parks itself — pushed up and faded — and a drawer comes in off the bottom edge carrying the word and the box. On Ok it goes back down and the note is left on the word, ellipsized to one line. The modal's own height never changes, so nothing behind it moves either.

Which words carry one

A badge that says there is writing here

A note is invisible until you land on the word, which is no good in a grid of twenty-eight or in a category card that lists what you picked. Three ways to say it, switched live — every demo on this page follows the choice.

The icon is the one worth the width. The dot and the rule are free — they are paint inside padding the pill already has — but both read as a rendering artefact until someone tells you what they mean. The glyph says writing on its own, and because a noted word is always a marked one, the badge never appears on a word that was not already drawn differently: a row can only grow when you add a note to it, by about one character, and never under the finger that is tapping something else.

Reading them against each other

What each one costs

A — In the stripB — Make room
Keystrokes Identical. N, type, Enter. The difference is entirely what the eye sees.
What moves One line appears below the definition. In the grid, no word above it shifts. The whole screen travels and dims. Legible, but it is the biggest movement in the picker.
Where the eye lands Where it already was — the word is a few pixels above the box. On the drawer, which names the word again because the grid behind it is now unreadable.
Room to type Half a modal, sharing the line with the key hint. Full width, and space for a second line later if a note ever wants one.
On a phone The keyboard covers the bottom of the modal, and the box is at the bottom. It has to scroll into view. The drawer is what the keyboard shoves up, and it is the only thing that needs to stay visible.
Fits the house rules Yes as drawn: the grid never shuffles, the pill never changes width. Yes, but it introduces a fourth screen state to the machines — browsing, sifting, walking, and writing.

Ship A, keep B's drawer for the phone. A note is a handful of words, and the strip is already the place the screen explains a word — putting the box there costs one line and no new screen. B earns its animation only where the software keyboard makes the bottom of the modal unusable, which is exactly the case A struggles with.

Both draw the resting note the same way, and that is the part worth keeping either way: a pencil rule painted inside the pill, which changes no width, and one ellipsized line wherever the word is being explained in full.

What it touches

Where a note has to live

A note is picked state, so it belongs beside visited in the two picker machines and has to survive the round trip through the fence in the note — which is where the real design question is, not in the keystrokes. 

- Angry: irate (still about the meeting), livid, resentful

A parenthesis after the word keeps the bullet readable with the plugin off, and keeps resolve.ts's rule that the words alone say which inventory a block is. The cost is that a note may not contain a closing parenthesis or a comma without an escape — worth settling before any of this is built, because it is the part that ends up in someone's vault.
